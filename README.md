# Stone_Paper_Scissor
Rock Paper Scissor Game
This is a Rock Paper Scissor Game code.

Features:
User select their options (1 for 🪨 2 for 📄  3 for ✂️).
System select its choice randomly as "random.choice" function is use.
Displays both player and computer choices.
Both choices are compare to decide the winner.
Shows the result of each round.
Option to play multiple rounds.

Game Rules:
Rock vs Paper then Paper wins
Rock vs Scissors then Rock wins
Paper vs Scissors then Scissors wins

Technologies Used:
Python 3
random module
Conditional statements
while loops
User input and error handling

How to Run:
Step1: Make sure Python 3 is installed.

Step2: Clone this repository
git clone <https://github.com/KAM-Aryan-RM/Stone_Paper_Scissor>

Step3: Navigate to the project folder
       cd Stone_Paper_Scissor
       
Step4: Run the game
       python Code.py

How to Play:
🪨 - 1
📄 - 2
✂️ - 3

After each round, enter:
1 to play again
0 to exit the game
